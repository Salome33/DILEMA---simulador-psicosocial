# NeuroCommand: Arquitectura de 70+ Vistas

## 1. Módulo de Estudiante (25+ Vistas)
- **Acceso:** Login, Biometría, Recuperación.
- **Onboarding:** Bienvenida, Tutorial Interactivo (3-4 pasos), Consentimiento Ético.
- **Dashboard:** Vista Principal, Historial de Casos, Logros/XP.
- **Briefing:** Selección de Caso, Dossier de Sujetos, Objetivos Formativos.
- **Simulación Activa:** Escenario Hospitalario (múltiples estados), Escenario Comisaría, Diálogos dinámicos, Toma de decisiones.
- **Herramientas:** Biblioteca Digital, DSM-V (Trastornos, Criterios), Protocolos Legales, Calculadoras de Escalas.
- **Post-Simulación:** Bitácora de Reflexión (Input, Revisión), Informe Final, Análisis de Decisiones, Recomendaciones.

## 2. Módulo de Docente (25+ Vistas)
- **Control:** Dashboard Global, Estado de Grupos, Alertas de Sesgo.
- **Gestión:** Listado de Grupos, Detalle de Estudiante, Revisión de Bitácoras.
- **Contenido:** Gestor de Casos, Editor de Narrativas, Banco de Multimedia.
- **Evaluación:** Configurador de Rúbricas (Criterios, Niveles), Mapa de Decisiones, Ponderaciones.
- **Analítica:** Reportes de Errores Frecuentes, Comparativa de Grupos, Historial de Cambios.

## 3. Módulo de Administrador (20+ Vistas)
- **Sistema:** Dashboard de Infraestructura, Latencia de Red, Carga de Nodos.
- **Usuarios:** Directorio, Creación de Entidades, Gestión de Permisos.
- **Seguridad:** Logs de Auditoría, Protocolos de Encriptación, Control de Acceso.
- **Mantenimiento:** Backups, Reinicio de Servicios, Configuración Global.

## 4. Vista General (Final)
- Mapa de navegación completo (Sitemap visual).
